# Shanxin Chen 个人主页

## 修改内容

打开 `index.html`，搜索下面的中文注释即可定位对应内容：

| 搜索词 | 可修改的内容 |
| --- | --- |
| 侧栏 | 头像、姓名、邮箱、研究方向 |
| 个人简介 | 简介与当前工作 |
| 教育经历 | 学校、学位、时间、导师 |
| 研究与项目 | 项目介绍、时间、指标 |
| 论文与专利 | 标题、作者、发表状态、链接 |
| 荣誉与奖项 | 年份、奖项名称 |
| 社区与任职 | 任职经历与介绍 |

直接修改标签之间的文字，例如 `<h3>` 与 `</h3>` 之间的学校名称。
修改链接时编辑 `href="..."`，修改头像时编辑 `src="assets/portrait.jpg"`。
保留 `class` 和 `id`，它们用于页面样式和导航。

新增项目、论文或经历时，复制对应的一整段 `<article ...>` 到 `</article>`，再修改其中内容。
新增奖项时，复制一整段 `<li>` 到 `</li>`。
中文注释只在源码中显示，访客不会在网页上看到。

## 预览与发布

保存后，用浏览器打开 `index.html`，刷新即可预览。也可以使用 VS Code 的 Live Server 扩展。
确认后提交并同步到 GitHub；线上页面的更新取决于仓库的 GitHub Pages 部署状态。

页面样式在 `style.css`，导航高亮逻辑在 `app.js`。
